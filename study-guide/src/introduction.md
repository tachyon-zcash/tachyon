# Introduction

This study guide accompanies The Tachyon Book, which lives beside it in the
`book` directory of the same repository. The book specifies Tachyon. The guide helps a reader learn it, by setting
Tachyon beside the shielded protocols that Zcash already runs.

Each page answers one question that a student of the book is likely to ask.
Each page names its sources, so that a reader can check every claim against
the Zcash Protocol Specification or against the book itself.

Tachyon is a draft, and the book changes as the design changes. Where the guide
and the book disagree, the book is right and the guide is out of date.
